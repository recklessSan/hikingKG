# Инструкция: декларация УСН при закрытии ИП
## Программа «Налогоплательщик ЮЛ» на Mac

**Ваш случай:** УСН 6%, без сотрудников, закрытие ИП в октябре 2026.

**Сроки при закрытии в октябре 2026:**
- декларация — до **25.11.2026**
- уплата налога — до **28.11.2026**
- фиксированные взносы за период до закрытия — в течение **15 дней** после снятия с учёта

---

## 0. Запуск на Mac

Официальной версии для macOS нет. Варианты:

1. **VirtualBox + Windows** — самый стабильный способ
2. **Wine + XQuartz** — возможны сбои

Скачать программу: сайт ФНС → «Программные средства» → **«Налогоплательщик ЮЛ»**.  
Нужна актуальная версия (форма УСН с 28.02.2026, приказ ФНС ЕД-7-3/1017@).

---

## 1. Данные налогоплательщика

1. Меню **Настройки → Налогоплательщики → Добавить**
2. Вид: **Индивидуальный предприниматель**
3. Заполнить: ФИО, ИНН, телефон, код ИФНС, ОКТМО, ОКВЭД
4. Сохранить

---

## 2. Создать декларацию

1. **Документы → Налоговая отчётность** (или мастер ввода)
2. Найти: **«Налоговая декларация по налогу, уплачиваемому в связи с применением УСН»**
3. Год: **2026** → **Ввод и печать документа**

---

## 3. Титульный лист

| Поле | Значение |
|------|----------|
| Налоговый период | **50** (прекращение деятельности) |
| Отчётный год | **2026** |
| Номер корректировки | **0** |
| Код ИФНС | ваша инспекция |
| По месту нахождения (учёта) | обычно **120** для ИП |
| ФИО над подписью | **не заполнять**, если подписываете сами |

---

## 4. Раздел 2.1.1 (заполнять раньше раздела 1.1)

Добавьте раздел кнопкой **«++»**, если не активен.

- **Строка 102** — признак налогоплательщика: **2** (без выплат физлицам)

### Доходы нарастающим итогом (до даты закрытия в ЕГРИП)

| Строка | Что указать |
|--------|-------------|
| 110 | доход за 1 квартал |
| 111 | доход за полугодие (янв–июнь) |
| 112 | доход за 9 месяцев (янв–сен) |
| 113 | доход с 01.01 до даты закрытия |

Ставка в строках 120–123: **6** (или ваша региональная).

Нажмите **«Р»** (расчёт) — строки 130–133 заполнятся автоматически.

### Страховые взносы (только уже уплаченные)

| Строка | Что |
|--------|-----|
| 140–143 | сумма взносов к вычету по периодам |
| 150 | фиксированные взносы |
| 160 / 161–162 | 1% с дохода свыше 300 000 ₽ |

Ориентир при закрытии **15.10.2026** (ИП с 01.01.2026): фиксированные взносы ≈ **45 356,61 ₽**.

Снова нажмите **«Р»**.

Без сотрудников налог можно уменьшить взносами **до 0**.

---

## 5. Раздел 1.1

1. Добавить раздел **«++»**
2. Указать **ОКТМО**
3. Нажать **«Р»**

Программа проставит:
- сумму к доплате (стр. 100), или
- сумму к уменьшению (стр. 110), если взносы/авансы перекрыли налог

Раздел **2.1.2** (торговый сбор) не заполняйте, если торговый сбор не платите.

---

## 6. Сохранить и сдать

1. Выгрузка → файл **XML** (или Печать → PDF/бумага)
2. Способы сдачи:
   - лично в ИФНС / через представителя
   - почта с описью вложения
   - по ТКС с УКЭП

---

## Аванс за 9 месяцев

Отдельно «заявлять» аванс не нужно — по УСН нет декларации на авансы.

Если закрываете ИП в октябре и сдаёте итоговую декларацию:
- платите **итоговый налог** до 28.11.2026
- учитываете уже уплаченные авансы за 1 квартал и полугодие

Отдельный аванс до 28 октября нужен только если к этой дате ИП ещё не закрыто.

---

## Частые ошибки

- код периода **34** вместо **50**
- ФИО в поле подписи у ИП
- взносы в вычете, которые ещё не уплачены
- доход в стр. 113 не до даты закрытия в ЕГРИП
- устаревшая версия программы → неверная форма

---

## Чек-лист после закрытия ИП

- [ ] Заявление Р26001 подано, запись в ЕГРИП есть
- [ ] Фиксированные взносы рассчитаны и уплачены
- [ ] Декларация УСН с кодом **50** сдана
- [ ] Налог УСН уплачен (если есть к доплате)
- [ ] Онлайн-касса снята с учёта (если была)
- [ ] Расчётный счёт закрыт (по желанию, обычно после)

---

Документ подготовлен как памятка. Перед сдачей сверьте цифры с личным кабинетом ФНС и актуальной формой декларации.
