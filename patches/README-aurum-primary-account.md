# Aurum: основной счёт (is_primary)

Патч добавляет галочку «Основной счёт». Выбранный счёт всегда первый в списках
и подставляется по умолчанию в форме расходов/доходов.

## Как применить на Mac

```bash
cd /путь/к/Aurum
git apply /путь/к/aurum-primary-account.patch
# или:
# git am /путь/к/aurum-primary-account.patch

docker compose up -d --build
```

## Как пользоваться

1. Счета → Элкарт → карандаш (изменить)
2. Включить галочку **Основной счёт** → Сохранить

В списке появится бейдж «основной»; при новом расходе Элкарт будет первым.
